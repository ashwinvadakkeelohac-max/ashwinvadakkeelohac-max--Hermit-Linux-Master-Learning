# Linux Arsenal - Interactive Linux Learning Platform
**Modified by Ashwin Vadakkeel (aka Hermit)**

## Highlights
- **Multi-User Profiles:** Click the user profile button in the top navigation bar to create, switch, or delete user profiles. Each user has isolated XP, level, streak, skill progress, command history, achievements, Easter egg discoveries, and completed challenges.
- **Completed Challenges Marking & Persistence:** Completed challenges are saved per user in `localStorage`, marked with a green border and `✓ Completed` badge, and filterable via the **Completed** tab.
- **Full Bug Fix Suite:** Fixed skill progress bars, `commandsLearned` tracking, terminal prompt path updates, XSS escaping, Leaderboard 6-column alignment, challenge pagination, Settings modal, and Analytics charts.
